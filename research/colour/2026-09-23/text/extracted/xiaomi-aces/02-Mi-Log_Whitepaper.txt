1 Introduction




    The Mi-Log profile employs a logarithmic curve and an extensive color gamut, mak-
ing it a scene-referred encoding. The application of logarithmic encoding allows for a
more efficient distribution of limited bits depth resources across varying exposure stops,
thereby enhancing the video’s dynamic range. Log captures are not designed for immedi-
ate viewing; they are intended to function as source clips for post-production processes.

3 Transfer Function

    The Mi-Log Curve serves as the transfer function in Mi-Log video encoding. It is a
scene-referred logarithmic function defined by dedicated encoding and decoding func-
tions. Notably, the Mi-Log Curve is tailored for 10-bit encoding, marking it as the minimum
quantization level suitable for this logarithmic encoding scheme.

Figure 2 shows the relationship between stops relative to 18% gray and their correspond-
ing brightness levels, and Figure 3 corresponds to the Log Curve output values, with the
horizontal axis representing 18% gray scene reflection and the vertical axis representing
the Log Curve output values.

4 Color Space




    The color space defines the representation of colors. Mi Log employs RGB primaries
and color space conversion matrices outlined in the ITU-R BT. 2020-2 specification. The
white point is aligned with the D65 illuminant, and all chromaticity values are specified
using the CIE 1931 2 Degree Standard Observer Colorimetry.
