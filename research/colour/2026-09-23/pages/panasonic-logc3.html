About extended function for DC-GH6 / GH7 / S1M2 / S1M2ES / S1RM2

Dear Customer,
We would like to thank you for purchasing Panasonic LUMIX.
This section explains the extended functions([ARRI LogC3] is added to [Photo Style]) that bceome avalable by using an Update Software Key (DMW-SFU3A).

Model Number / Version DC-S1M2 Ver.1.1 or more
DC-S1M2ES Ver.1.1 or more
DC-S1RM2 Ver.1.2 or more
DC-GH6 Ver.3.0 or more
DC-GH7 Ver.1.0 or more

Procedure to activate the extended function

Please read through the guidance before starting the update.
< Necessary Supplies >
- Upgrade Software Key "DMW-SFU3A(sold separately)"
* Please read the installation guide of DMW-SFU3A carefully.
- Use the battery fully charged (Update may not be completed if the battery power is not enough)
- Memory Card (Format the card in the camera beforehand)

STEP 1. Check the firmware version

⇒ [Setup] ⇒ [Version Disp.]
For the latest firmware information and for firmware downloads, refer to the support site,
https://panasonic.jp/support/global/cs/dsc/download/index.html

STEP 2. Export the device information

  1. Insert the Memory Card into the camera.
    2. - Insert a Memory Card formatted with the camera
  2. Select the menu.
    3. ⇒ [Setup] ⇒ [Activate]
  3. Press / to select [Export Serial Code] and then press [MENU/SET].
    4. - Confirmation screen is displayed. It is executed when [Yes] is selected.
    - The device information (file name: SERIAL.LIST) will be saved to the " PRIVATE\PANA_GRP\PAVC\LUMIX\ACTV " folder on the Memory Card.

STEP 3. Acquire the activation code

  1. Insert the Memory Card containing the device information into a PC connected to the Internet.
  2. Using a browser on the PC, access the activation code generation site, and follow the on-screen instructions to acquire an activation code.
    3. Activation code generation Site:
    https://eww.pavc.panasonic.co.jp/enhance/ActivationTop/en
    - The activation code (file name: ACTIVE.LIST) will be saved to the " PRIVATE\PANA_GRP\PAVC\LUMIX\ACTV " folder on the Memory Card.

STEP 4. Import the activation code

  1. Insert the Memory Card containing the activation code into the camera.
  2. Select the menu.
    3. ⇒ [Setup] ⇒ [Activate]
  3. Press / to select [Import Activation Code] and then press [MENU/SET].
    4. - Confirmation screen is displayed. It is executed when [Yes] is selected.
    - A message will be displayed, prompting you to turn off and on the camera. Turn off the camera, and then turn it on.
