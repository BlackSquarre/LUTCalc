# H13 PNG iCCP CRC 阶段验收

日期：2026-09-25。Goal 仍 active。本阶段只校验嵌入 ICC 来源数据的完整性，不改变 ImageIO 像素解码和任何颜色计算。

## 契约先行

`LUTImageChecks` 新增研发夹具：复制嵌入 sRGB PNG，只翻转 `iCCP` chunk 的 CRC 字节，然后要求解码拒绝。实现前运行该入口得到 `bad iCCP CRC accepted`，契约按预期失败。

随后在 `SourceICCReader` 中按 PNG chunk type + payload 计算 CRC-32，并与 chunk 尾部的声明值比较；不匹配时返回 `invalidPNG`，由图像解码入口转换为 `invalidICCProfile` 或系统提前报告的 `invalidImage`。
