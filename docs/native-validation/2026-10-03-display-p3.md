# 2026-10-03 Display P3 D65 色域后端非 UI 验收

## 范围

本阶段补齐 Display P3 的可追溯色域身份和 Double 矩阵路径，不实现屏幕色彩管理或 UI 预览。Display P3 使用公开的 D65 原色；传递函数仍由独立的 `TransferID` 选择，默认可配合 W3C sRGB 曲线，不能把 Display P3 原色误写成一个新的 gamma。

实现内容：

- 新增 `ColorSpaceID.displayP3 = display.p3-d65.v1`。
- 新增 `ColorPrimaries.displayP3`，原色为 R `(0.680, 0.320)`、G `(0.265, 0.690)`、B `(0.150, 0.060)`，白点 D65 `(0.3127, 0.3290)`。
- 在 `AlgorithmCatalog` 登记 `Display P3`、`P3-D65` 别名和 Apple CoreGraphics 公开来源。
- 复用既有解析矩阵算法，没有打包 LUT、采样数组或系统隐式色彩管理。

## 契约与独立参照

先新增 3 项契约：目录身份与原色、独立高精度矩阵、同色域 sRGB transfer round-trip。由 80 位 Decimal 独立计算得到的 RGB→XYZ 矩阵为：

```text
0.4865709486482162854  0.2656676931690929451  0.1982172852343625020
0.2289745640697488402  0.6917385218365061590  0.0792869140937450008
0.0000000000000000000  0.0451133818589025756  1.0439443689009758439
```

原生 Double 与该参照的最大绝对误差低于 `2e-15`。
