# H11 Panasonic V-Log / V-Gamut 阶段验收

日期：2026-09-24。状态：**官方曲线、明确 Bradford 的最小跨色域链及研发 CUBE 已验证；H11、CORE-03 和完整迁移仍未完成。** 界面维持功能草稿，未声称 Panasonic 相机预设与设备交互已验收。

## 来源与选择

- [Panasonic《V-Log/V-Gamut Reference Manual》Rev.1.0](https://pro-av.panasonic.net/en/cinema_camera_varicam_eva/support/pdf/VARICAM_V-Log_V-Gamut.pdf)，本地 `research/colour/2026-09-24/VARICAM_V-Log_V-Gamut.pdf`，SHA-256 `d8a1837725abcca5da348b2dc6f212446db6a598cb61b093891af7ecbc0c8dcc`。第 4 页给出分段曲线及 10-bit 除以 1023；第 5 页给出 V-Gamut 原色；第 6 页给出 RGB→XYZ 与公布的 ACES 矩阵。
- [ACES `CSC.Panasonic.VLog_VGamut_to_ACES.ctl`](https://github.com/aces-aswf/aces-input-and-colorspaces/blob/main/panasonic/CSC.Panasonic.VLog_VGamut_to_ACES.ctl)，本地同名 CTL SHA-256 `d3aa9207e4073bf1770edf992f34ccb38a0e7762bb55f2927b7db3aa22ba4913`；Transform ID `urn:ampas:aces:transformId:v2.0:CSC.Panasonic.VLog_VGamut_to_ACES.a2.v1`。
- ACES `Lib.Academy.ColorSpaces.ctl` SHA-256 `4f07503e00127b00719416d63446d9a6b504798111d94f3860eb74754b6fb00a`。其 `calculate_rgb_to_rgb_matrix` 默认 Bradford；从原色和白点计算，不使用代码采样表或厂商 LUT。研发资料与 PDF/CTL 均不打包进 App。
- 旧 `js/gamma.js` SHA-256 `250017d8efe758f3555148ba9fcb923698add0ac7d9380fa290716eb98e0821e`，只用于研发比较。旧 `LUTGammaLog` 对输入使用 0.9 标度；比较前明确还原标度。

手册六位 ACES 矩阵与 ACES CTL 使用 Bradford 从所列原色计算的矩阵最大绝对差为 `0.00023370413152989933`，**大于六位小数舍入量，原因尚未定论**。当前 `panasonic.vlog-to-linear-ap0.v1` 明确选择 ACES CTL 所用 Bradford 解析矩阵；手册公布矩阵保留为独立差异证据，不用 `2e-12` 门槛要求两者相等。CAT02 路径也不能冒充该 ACES 转换。通用设置新增显式 `adaptation`，缺省仍为 CAT02；旧项目 JSON 缺少该字段时按 CAT02 读取并保持旧版缺省写出形态，Bradford 设置明确保存。

手册常数在 `scene=0.01` 和 `data=0.181` 附近存在微小不连续：编码左支极限为 `0.181`，右支为约 `0.18099968876500305`；解码左支极限为 `0.01`，右支约 `0.010000055577655825`。实现遵照手册的 `<`/`>=` 分支，不修改常数、移动边界或强制连续；临界邻点纳入冻结夹具。手册限定名义数据域，CUBE 的 `[0,1]` 节点在其内；曲线对域外有限数继续用相同解析式作扩展，域外准确度未作为官方定义宣称。

## 先验契约、实现与文件

先创建 `LUTVLogChecks` 与独立 Decimal 夹具，Release 首次编译因缺 `VLogTransfer`、V-Gamut 与 Bradford 等符号失败；随后实现 Swift 公式、原色、适应和注册表。冻结门槛保持 `scaledError ≤ 2e-12`；`80/120` 十进制位计算后两次转 Double 一致。分段边界依据**输入 Double 的确切阈值**选支，避免把二进制 `0.181` 错判成精确十进制常数下方。

主要新增/修改：`Native/Packages/LUTKit/Sources/LUTCore/VLogTransfer.swift`、`Matrix3x3.swift`、`TransformPlan.swift`、`LUTCatalog/AlgorithmCatalog.swift`、`LUTVLogChecks/main.swift`、`LUTReferenceCLI/main.swift`、`LUTCatalogChecks/main.swift`、`Package.swift`、`tools/native-validation/generate-vlog-reference.py`、`compare-vlog-legacy.js`、`verify-vlog-cube.py`、`verify-native-subset.sh`、`tests/fixtures/native-contracts/vlog-panasonic-reference.json`。研发 CLI 预设为 `vlog-linear-ap0`；当前内置登记为 9 条曲线、7 个色域、9 个研发预设。

关键文件 SHA-256：Swift 公式 `f3d9ef58a8e66fedfafed72f5a1495fba0ea4533fce1c7d5238e946be06cedba`；矩阵 `7e6d478813c984471700b59d3de0fe7c65c5537e4d6f1ce908d65d59d294208c`；计划 `b8cec3cb8b5d01a9c4976eabdf98a2f612cc2122594c6bbcdcc01160d6527ab3`；独立生成器 `015ed84dc35f811dad69b073dafb4c41f59b7f625a4b028b889d1eba4c03f2ca`；冻结 JSON `bdd8b8fc1aa049b0b569e02876b8eb6ea8cfd2d7aeb970a84af3a19d5b87b438`；网格比较器 `400e6b54297c679936089d313c7d3488fb978f7a7d33e1e252628bf018ceb79a`。
