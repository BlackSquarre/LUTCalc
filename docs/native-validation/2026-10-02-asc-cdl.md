# 2026-10-02 ASC-CDL 旧工作空间阶段验收

## 范围与版本

接续[暂缓 UI 后的范围核对](2026-10-02-non-ui-scope-audit.md)，本包实现 FULL-03 的 ASC-CDL 算法、生成、项目存储和请求快照子集。没有新增界面控件或进行 Finder／Files 操作；`LUTSharedUI` 的改动只保证参数化 gamma 更新时保留新配置，其测试是程序化文稿／导出服务契约。

新增 `ASCCDLSettings` 和 prepared `LegacyASCCDL`，算法身份为 `lutcalc.asccdl-working-linear.v1`。这是保留旧 LUTCalc 工作空间的明确版本，不声称标准 Rec.709 ASC-CDL 认证。

3D 阶段 8 位于曝光之后、输出色域之前。Sony S-Gamut3.cine／D65 工作空间 RGB→XYZ 的 Y 行由原色色度方程求解；启用 CDL 时，相同输入／输出色域也经过工作空间转换。scene 值除以 `0.9`，执行 slope→offset→power；负 SOP 值跳过 power。饱和度使用实际工作空间 Y 系数，最后乘 `0.9` 返回 scene 值。配置缺失或 disabled 保持原无调节行为。

旧 1D 只执行 SOP，跳过色域矩阵与饱和度。新增独立通道入口并接入 1D 生成器，目前要求输入输出色域相同。1D 与启用饱和度的 3D 不等价，这属于显式保留的旧语义。

旧输入字段没有硬参数限幅，有限负 slope／saturation、零／负 power 均保留。奇点、溢出及非有限结果明确失败并携带阶段／节点诊断；不复制旧 NaN→0，不增加随意 clamp。最终生成仍使用 Double。

## 项目 schema 4

`ProjectManifest.currentSchema` 升为 4。配置、算法身份、撤销历史、不可变请求与编辑快照保存 CDL；disabled 配置仍记录算法版本。原生 schema 1–3 明确迁移到当前内存模型，新配置缺失仍为 `nil`，读取不改写源文件。旧 schema 出现 CDL 字段、未知嵌套字段或算法版本错配均拒绝，包括直接 JSONDecoder 路径。

用户 LUT 后置配置和原始资产继续保留。此次不是旧 App 设置导入，不恢复厂商采样表。

## 先行契约与实际修正

先写核心契约，因新类型不存在而编译失败（`contract-red.log`，退出 1）。存储测试初次编译失败来自测试缺少 in-memory 1D sink 及错误闭包引用；修正后实际暴露 schema／字段／版本缺失，共 11 个失败（`persistence-red2.log`，退出 1）。实现后 Debug 8 项通过。

新文稿集成测试初次误用导出方法名和 Optional 数值断言，编译退出 1；修正后定向 Debug 10 项全部通过（`debug-final.log`）。最终复核发现跨色域测试中的错误顺序比较使用了未出现的条件点，改成检查全部 64 点中的最大差异，必须大于 `1e-3`；产品算法和 `2e-12` 精度门槛没有改变。最终 Release 全包验证该断言。

所有中间失败日志保留，不将其计为产品通过证据。
