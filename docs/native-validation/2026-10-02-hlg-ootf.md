# 2026-10-02 HLG 显示 OOTF 非 UI 阶段验收

## 范围

本包补齐 HLG 显示 OOTF 的 Swift `Double` 数学内核，不涉及 UI、屏幕 HDR/EDR 呈现或系统显示配置。场景 OETF 仍由既有 `HLGTransfer` 负责；本包单独表达峰值亮度、黑位、nits/归一化标度、BBC 输入/输出系数和 RGB 亮度耦合。

来源为 ITU-R BT.2100 HLG 定义及旧实现 `js/gamma.js:LUTGammaOOTFHLG`。产品运行时不读取 JavaScript 或 LUT 资源。

## 实现与契约

- 新增 `HLGOOTF`，支持输入/输出侧独立峰值和黑位、nits 与除以 1000 的归一化标度、BBC 系数 `2.821251498`、标量前向/逆向及 RGB 亮度耦合。
- 严格拒绝非有限值、无效峰值/黑位和逆向超出显示域的输入；始终使用 `Double`，峰值裁切是显式 OOTF 语义。
- 先运行缺失实现的契约红灯，再实现内核；最终 `HLGOOTFContractsTests` 4 项通过。

## 数值结果

- 90 位 Python `Decimal` 参照已生成于 `artifacts/2026-10-02-hlg-ootf/decimal-reference.json`。
- 完整 `swift test --package-path Native/Packages/LUTKit` 通过：530 项执行、0 失败、2 项因既有 `.labin`/NCP 外部夹具缺失而跳过。命令、机器摘要、日志及源码哈希保存在对应 artifact 目录。
- 默认 1000 nit、黑位 0 的 scene 0.18 输出为 `6.476039825649833...` nit；400 nit、BBC 系数启用的 scene 0.18 输出为 `15.25646062288929...` nit；Swift 契约误差均低于 `2e-14`。
- RGB 亮度耦合前向/逆向往返误差低于 `2e-12`。
