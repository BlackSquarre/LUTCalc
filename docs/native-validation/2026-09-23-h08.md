## 实际命令与结果

`swift run --package-path Native/Packages/LUTKit LUTJobChecks` 与 `swift run -c release --package-path Native/Packages/LUTKit LUTJobChecks` 均通过。固定 17³ 非恒等计划在 1/2/4 worker 和 1/17/4096 节点块的九种组合中，与单线程 Double 生成数组逐节点精确相同；乱序缓存上限检查为 `≤2×workerCount`。按块注入写入失败得到 `failed`，按块注入取消得到 `cancelled`，两者均调用输出端 `abort`，未提交部分样本。流式文件在自有临时目录中生成 17³ CUBE，解析读回等于原 Double 样本；对已存在目标再次生成返回 `targetExists`，既有字节保持不变。

生成范围仍是 DJI D-Log2/D-Gamut2 → 曝光 +1 → 线性 AP0，数值参照与误差见 H06–H07 记录。此处验证的是调度与写入确定性，未把单一链路推广为全功能精度结论。
