# ICC MPE/device-link 剩余公开边界复核

## 范围

本轮只复核 `ICCMPETransform` 与 `ICCDeviceLinkTransform` 的剩余公开结构边界，覆盖 `mpet` 元素表、`cvst`、`samf`、`matf`、`clut`、ACS 占位元素、共享资源范围、通道链、有限浮点值以及 device-link `A2B0` 的 `mpet` 路由。未扩展 UI、平台或其他功能范围。

## 生产改动

本轮没有生产代码改动。当前实现已经具备以下可验证约束：

- 元素表数量、偏移、长度、四字节对齐和 checked arithmetic。
- 完全相同的共享元素范围允许；不同范围交叠拒绝。
- `curf` breakpoints 需要有限、归一化且严格递增。
- `samf` 仅允许出现在首段之后，并用前段末值作为隐含起点；末段延伸到归一化终点。
- `matf` 支持动态输入/输出通道并严格校验尺寸及有限 Float32 参数。
- `clut` 按 ICC 第一维最慢、最后一维最快顺序执行，严格校验网格与资源长度。
- `bACS`/`eACS` 仅在通道数相同的明确 pass-through 元素中执行。
- device-link 的 `A2B0` `mpet` 允许其声明的 link output channel count，不误用普通 PCS 限制；LittleCMS 2.19 真实 RGB/RGB profile 参照已在既有记录中保存。
