# 2026-10-02 Canon C-Log2/Cinema Gamut 非 UI 阶段验收

## 范围

本包只处理有公开 ACES CTL 的 Canon C-Log2/Cinema Gamut。固定提交为 `29b722bccd529460696a8382394504cae2e88419`；双向 CTL、URL、SHA-256 和最小来源说明见 `research/colour/2026-10-02-canon-clog2/` 及[研究记录](2026-10-02-canon-clog2-research.md)。产品运行时不读取 CTL、JavaScript 或 LUT 资源，使用 Swift `Double` 解析式和原色推导矩阵。

公开路径保留 CTL 的 `0.9` 场景标度；legacy 路径独立保留 `js/gamma.js`／`js/colourspace.js` 的九参数与历史线性语义。C-Log、C-Log3、Canon CP IDT 和真实 camera shoulder 没有借用 C-Log2 公式，仍明确拒绝。

## 代码和契约

- 新增 `CanonCLog2Transfer`，包含公开/legacy 双向分支、负值路径、非有限输入拒绝和独立零值边界。
- 新增稳定 `TransferID`：`canon.c-log2-published.v1`、`canon.c-log2-lutcalc-legacy.v1`；新增 `ColorSpaceID`：`canon.cinema-gamut.v1`。
- 接入 `TransformPlan`、输出编码、catalog 描述、两个 AP0 预设和三个已有 C-Log2 相机身份的 published/legacy resolver。C300 的 C-Log 与 CP IDT 身份继续拒绝。
- schema 从 20 升至 21；schema 1–20 偷带 Canon C-Log2 transfer、Cinema Gamut 或 disabled 调节引用均拒绝。既有 schema19 Blackmagic 读取字节保持不变。
- 首轮测试先验证缺失实现导致的编译红灯，再完成实现。

## 数值结果

- 核心契约：5 项通过，包含公开/legacy 标量、CAT02 矩阵、目录与相机默认、非有限输入。
- Canon Cinema Gamut → ACES AP0 CAT02 矩阵 9 个值与独立 Decimal 推导最大绝对误差低于 `2e-14`。
- published 与 legacy 各生成完整 `33³`、`65³` CUBE，共 `1,863,372` 个通道；逐点独立公式比较最大相对误差 `9.769962616701378e-15`，阈值 `2e-12`。
- 追加独立 Python `Decimal` 90 位参照：重新从 Cinema Gamut/AP0 色度、D65 白点和 CAT02 推导矩阵，并逐点读取四个实际 CUBE 文件。published 33³/65³ 最大相对误差分别为 `7.982003253097084e-15`、`1.128296346105484e-14`；legacy 33³/65³ 分别为 `8.916511832905497e-15`、`9.708411973185148e-15`，均低于 `2e-12`。参照脚本、完整矩阵、RMS、最差节点和实际文件路径见 `tools/native-validation/verify-canon-clog2-decimal.py` 及证据目录的 `independent-decimal-results.json`。这次参照独立于 Swift 测试内重复公式。

## 构建

实际工具链为 Xcode 27.0 / Swift 6.4 / SDK 27.0。以下命令均在仓库根目录执行：

```text
swift test --package-path Native/Packages/LUTKit --filter CanonCLog2ContractsTests
swift test --package-path Native/Packages/LUTKit --filter CatalogTransferSmokeTests
swift test --package-path Native/Packages/LUTKit --filter BMDGen5ProjectContractsTests
swift test --package-path Native/Packages/LUTKit --filter CanonCLog2ProjectContractsTests
LUTCALC_CANON_CLOG2_ARTIFACT_DIR=docs/native-validation/artifacts/2026-10-02-canon-clog2 swift test --package-path Native/Packages/LUTKit --filter CanonCLog2DocumentContractsTests
xcodebuild -project Native/LUTCalc.xcodeproj -scheme LUTCalcMac -configuration Release -derivedDataPath /tmp/LUTCalc-canon-build-20261002/macos CODE_SIGNING_ALLOWED=NO build
xcodebuild -project Native/LUTCalc.xcodeproj -scheme LUTCalcIOS -configuration Release -sdk iphoneos -derivedDataPath /tmp/LUTCalc-canon-build-20261002/ios CODE_SIGNING_ALLOWED=NO CODE_SIGN_IDENTITY='' build
xcodebuild -project Native/LUTCalc.xcodeproj -scheme LUTCalcIOS -configuration Release -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' -derivedDataPath /tmp/LUTCalc-canon-build-20261002/sim CODE_SIGNING_ALLOWED=NO CODE_SIGN_IDENTITY='' build
```

三个 Release 构建均退出 0 并记录 `BUILD SUCCEEDED`。CoreSimulator 初始化仍有内存告警；本包只计模拟器 generic Release 构建，不计 UI 或模拟器运行证据。构建日志、应用路径、源文件 SHA 和数值结果保存在 `docs/native-validation/artifacts/2026-10-02-canon-clog2/`。
