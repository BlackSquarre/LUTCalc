# Canon C-Log3 非 UI 阶段验收

## 范围

本阶段只接入有公开来源的 Canon C-Log3／Canon Cinema Gamut 标量传递、CAT02 到 ACES AP0 的现有矩阵路径、目录预设和项目 schema 门槛。没有把 C-Log3 扩写成 Canon 全机型模型，也没有新增 LUT、采样表或 UI。

## 来源与算法

- ACES 固定提交：`29b722bccd529460696a8382394504cae2e88419`。
- `CSC.Canon.CLog3_CGamut_to_ACES.ctl`：SHA-256 `4702bcbd323e81e223cf4ac3c779b49fee81e13888fcb170b97ac3df189f6aa1`。
- `CSC.Canon.ACES_to_CLog3_CGamut.ctl`：SHA-256 `0aeae01d472b3f7fcfcf095381d384032f13afef2bed599199c60aff082a23e5`。
- Swift 实现使用 `Double`，按 CTL 的负对数、线性段和正对数三段直接实现；Cinema Gamut 原色和 CAT02 矩阵沿用已有独立 Decimal 参照。
- 反向解码保留 CTL 分支和场景缩放 `0.9`，非有限输入显式拒绝。
