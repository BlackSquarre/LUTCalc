# GoPro GP-Log2 base-600 传递函数验收

## 范围

根据已归档的 `research/colour/2026-09-23/reference-code/gopro-gplog2.html`，实现 GP-Log2 的基础 base-600 标量子集：

- 编码：`log(599*x + 1) / log(600)`；
- 解码：`(600^v - 1) / 599`；
- 输入和输出定义域严格限制为 `[0,1]`。

负值扩展、曝光风格、Rec.2020→Rec.709 矩阵、相机预设和 UI 均未接入。

## 接线与契约

新增独立 `TransferID.gpLog2`、`GPLog2Transfer`、`TransformPlan` 输入解码、`NativeOutputEncoder` 输出编码、目录描述和输出数据单位分类。没有复用 `goProProtuneLUTCalcLegacy`，也没有加入查表数据。

独立 80 位 Decimal 参照脚本为 `tools/native-validation/probe-gplog2.py`。重算结果为 `0.18`→`0.7331165721407825605965489544`、`0.5`→`0.8919040948532175844901100017`，反向重算分别回到 `0.18` 与 `0.5`；Swift Double 与高精度结果的差异低于 `2e-16`。负值、超范围和非有限输入均拒绝。

## 未覆盖范围

该项只关闭 base-600 `[0,1]` 标量 transfer。它不证明 GoPro 相机设备范围、负值 log 扩展、Rec.2020 色域、曝光风格、旧 Protune 兼容、完整 GP-Log2 工作流或 Goal 完成。
