# 2026-10-05 CIELAB CIEDE2000 算法验收

## 范围

本轮补齐 CIELAB 数学范围中的 CIEDE2000 距离。实现位于 `Native/Packages/LUTKit/Sources/LUTCore/CIELAB.swift` 的 `CIELABColor.deltaE2000(to:)`，依据 Sharma、Wu、Dalal，*The CIEDE2000 Color-Difference Formula: Implementation Notes, Supplementary Test Data, and Mathematical Observations*, Color Research and Application 30(1), 21–30 (2005), DOI `10.1002/col.20070` 计算。该指标要求两种颜色来自相同的 Lab 白点和观察条件；实现不做白点适应、色域映射、裁切或显示转换。

项目内部 `L*` 保存为 `0...1`，实现只在 CIEDE2000 内部转换为标准 `0...100`；`a*` 与 `b*` 保持传统单位。没有改动 CIELAB 编码、ICC 路由、RGB `TransformPlan` 或项目 schema。

## 先行契约与实现

契约覆盖四组 Sharma 公开参考对、零色度、色相跨越 0/360 度边界和交换输入后的对称性。先在旧实现上加入 `deltaE2000` 调用，编译因缺少成员失败；随后加入 Swift `Double` 实现。实际命令：

```sh
swift test --package-path Native/Packages/LUTKit -c debug --filter CIELABContractsTests
python3 tools/native-validation/probe-cielab-deltae2000.py | tee /tmp/lutcalc-cielab-deltae2000-decimal-20261005.json
swift test --package-path Native/Packages/LUTKit -c release --filter CIELABContractsTests | tee /tmp/lutcalc-cielab-deltae2000-release-20261005.log
```

工具链为 Xcode 27.0（27A266a）、Swift 6.4、Apple Silicon macOS、Python 3 `decimal` 90 位精度。Debug／Release 定向 `CIELABContractsTests` 均为 6 项通过、0 项失败。

## 未覆盖范围

- 只关闭同一 Lab 白点和观察条件下的 CIEDE2000 距离数学子集，不实现 CAM、色貌模型或完整 CIELAB 工作流。
