# Rec.2020 12-bit legacy 解析式验收

## 范围

本轮只关闭旧 `js/gamma.js:LUTGammaGam` 的 `Rec2020 12-bit` 解析式注册。实现使用 Swift `Double` 和可追溯分段公式；没有加入厂商 LUT、`.labin`、采样表或拟合模型。UI、HDR/EDR/OOTF、ICC 全量、LUTAnalyst 全量、目标软件往返和真机性能不在本轮范围。

## 公式与兼容语义

- 来源：`js/gamma.js:LUTGammaGam`，参数为 `[1/0.45, 4.5, 0.0993, 0.0181, 0.08145, 1.9]`。
- 正向 legal：`x >= 0.0181` 时为 `1.0993*x^0.45-0.0993`，否则为 `4.5*x`。
- 逆向 linear：`y >= 0.08145` 时为 `((y+0.0993)/1.0993)^(1/0.45)`，否则为 `y/4.5`。
- Data 包装保持旧常数：`data = legal*0.85630498533724 + 0.06256109481916`。
- 旧实现的正向 `0.0181` 与逆向 `0.08145` 是独立切点，精确边界处存在历史分支不连续；契约按旧行为验证，没有擅自平滑或改变阈值。
- 旧灰度场景标度保留：legacy 与 scene 之间使用 `0.9`／`1/0.9`，最终生成路径使用 `Double`。

## 契约与实现

- 新增 `Rec2020TwelveBitTransfer`，接入 `TransformPlan`、`NativeOutputEncoder`、`OutputCodeUnits`、`AlgorithmCatalog` 和 `LUTReferenceCLI`。
- 新增 `TransferID.rec2020TwelveBit` 与预设 `rec2020.12bit-legacy-exposure-one.v1`，和 Rec.2020 10-bit 保持独立身份及计划版本。
- 契约覆盖分段常数、独立切点、Data 包装、标量往返、非有限输入拒绝、目录注册和计划身份区分。
- 新增后同步修正目录契约中参数化 Gamma 家族数量：`17` 增为实际 `18`。

## 独立全网格核验

使用 Python `Decimal` 精度 80 独立重读 Swift 导出的完整 CUBE，按真实 `0...1` RGB 网格坐标计算 `exposureStops = 1` 的完整变换链。脚本不调用生产 Swift 或 JavaScript。

| 网格 | 节点数 | 最大绝对误差 |
|---|---:|---:|
| 17³ | 4,913 | `1.9257070165983715e-16` |
| 33³ | 35,937 | `3.0724980301755193e-16` |
| 65³ | 274,625 | `3.0724980301755193e-16` |

产物、日志、Decimal 报告和 SHA-256 位于 `docs/native-validation/artifacts/2026-10-04-rec2020-12bit/`。
