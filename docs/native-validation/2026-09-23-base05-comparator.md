# BASE-05 旧完整链比较器统计与故障注入

日期：2026-09-23。接续[H06 Legal 范围阶段记录](2026-09-23-h06-legal-range.md)。本步为 Swift 与旧完整链 Float64 比较增加统计，并验证比较器能检出三种具体错误。旧引擎仅用于兼容性参照；独立公式参照和范围/矩阵契约仍单独判断。UI 未改动。

## 契约与修改

先对既有冻结夹具运行 Release 比较器并要求输出 `RMS` 与 `P99`，命令退出码 1，确认此前只有最大误差。修改 `Native/Packages/LUTKit/Sources/LUTContractChecks/main.swift` 后，比较器逐通道记录最大尺度化误差、最大绝对误差、尺度化 RMS、尺度化 P99（最近秩）、最差节点/通道及超门槛通道数；`2e-12` 尺度化门槛保持不变，任何超门槛通道仍令进程失败。

新增研发测试 `test-legacy-comparator-faults.py`：从冻结 17³ Data→Data 夹具派生单通道 `+1e-5` 扰动、整网格 R/G 轴索引交换、Float32 量化后再写回 Float64 三种临时数据；运行实际 Swift 比较器，要求每种都失败并输出超门槛统计。临时文件由测试自身管理，不改冻结夹具或 App。`verify-native-subset.sh` 在 Release 构建及正常对照后运行此测试。

## 仍缺的验收

这只是一个无调节 D-Log2/D-Gamut2 链的比较器：尚缺固定种子跨设置采样、逐阶段诊断、1D 旧完整路径、调节与限制、官方资料冲突项和全部旧预设。BASE-05 仍不勾选。本机仍无完整 Xcode/iOS SDK，XCTest、macOS/iOS/iPadOS `.app`、模拟器、真机和发布门槛均未由本步验证。
