## 可追溯公式

资料：`research/colour/2026-09-23/whitepapers/leica-llog-v1.9.pdf`。

编码（场景线性值 `LSR` 到 L-Log 数据值）：

```text
LSR <= 0.006:
  8 * LSR + 0.09
else:
  0.27 * log10(1.3 * LSR + 0.0115) + 0.6
```

解码：

```text
L-Log <= 0.1380:
  (value - 0.09) / 8
else:
  (10^((value - 0.6) / 0.27) - 0.0115) / 1.3
```

Swift 保持 `Double`，非有限输入和非有限结果拒绝。预设 `leica.llog-exposure-one.v1` 使用 L-Log → 线性场景、Rec.2020 同色域、+1 stop。
