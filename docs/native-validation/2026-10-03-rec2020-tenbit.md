# H11 BT.2020 10-bit 传递函数非 UI 阶段验收

日期：2026-10-03。状态：BT.2020-2 10-bit 场景 OETF 的 Swift Double 标量、计划、目录、项目往返和本地 CUBE 子集通过；完整标准显示链、第三方软件互操作、设备性能、签名发布和全量清单仍未完成。

## 来源与语义

来源为本地归档的 ITU-R BT.2020-2：

- PDF：`research/colour/2026-09-23/whitepapers/itu-bt2020-2.pdf`，SHA-256 `eed65cf78c95923964c5420ac4f60d1c83f68823c7a71b05a5e31818ebd03374`；
- 文本提取：`research/colour/2026-09-23/text/whitepapers/itu-bt2020-2.txt`，SHA-256 `7fc129ba5c4736c2c77e8d1cb15586688b7c559f11d6c08f18317bcd0478a6d6`。

BT.2020-2 第 3 表给出精确连续解的 `alpha=1.09929682680944...`、`beta=0.018053968510807...`，并规定实用值：10-bit 使用 `alpha=1.099`、`beta=0.018`，12-bit 使用 `alpha=1.0993`、`beta=0.0181`。本阶段只实现 10-bit 版本，未把旧 LUTCalc 的 `Rec2020 12-bit` 参数复制过来。

新身份为 `rec2020.bt2020-10bit.v1`，API 使用 scene-linear↔data 的独立路径；没有套用旧 `rec709.lutcalc-legacy.v1` 的 `legacyGrey02` 缩放。分段边界按实际 Double 比较，保留 `0.018`／`0.081` 实用常数造成的编码空隙；负值、超白值按相同解析式外推，非有限输入拒绝。输出单位分类使用完整 normalized data 包装 `64/1023` 与 `876/1023`，项目 `rangeBitDepth` 不改写该 10-bit 定义。

## 契约、实现与结果

先新增以下契约后实现生产代码：

- `Rec2020TenBitContractsTests`：分段常数、边界空隙、负值／超白、单调性、非有限拒绝、计划身份和输出单位；
- `Rec2020TenBitCatalogContractsTests`：稳定 ID、别名、来源和预设；
- `Rec2020TenBitProjectContractsTests`：当前 schema 的项目编码／解码保留传递函数身份。

生产接线包括 `Rec2020TenBitTransfer`、`TransferID`、`TransformPlan` 输入／输出分派、`OutputCodeUnits`、算法目录、目录检查和 `LUTReferenceCLI` 预设入口。没有新增内置 LUT、`.labin`、采样表或 Web/JavaScript 运行时。

使用工具链：Xcode 27.0（`27A266a`）、Apple Swift 6.4、Python 3.14.6，macOS arm64。

- Debug 定向 `swift test --package-path Native/Packages/LUTKit --filter Rec2020TenBit`：5 项通过；
- Release 定向同命令：5 项通过；`LUTCatalogChecks`：52 条曲线、18 个色域、48 个预设检查通过；
- 完整 Release：`swift test --package-path Native/Packages/LUTKit --configuration release --no-parallel`，8 个测试包共 629 项执行、0 失败，LUTFormats 2 项既有外部夹具按设计跳过；
- CUBE：`LUTReferenceCLI` 生成 17³ 与 33³、共 122,550 个 Double 通道；独立 90 位 Decimal 复算最大绝对误差 `1.7575598766671658e-16`，门槛 `2e-12`；
- macOS、iOS generic、iOS Simulator 未签名 Release `xcodebuild` 均退出 0；实际 3 个 App 包资源审计退出 0，无 `.js`、`.html`、`.c/.cc/.cpp`、`.labin` 或 WebKit/JavaScriptCore 直接链接。
