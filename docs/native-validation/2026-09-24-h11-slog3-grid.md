## 契约与实现

承接[标量与最小计划记录](2026-09-24-h11-slog3-scalar.md)。先在 `LUTSLog3Checks` 要求两个稳定预设 ID，初次运行以 `catalog source or identity` 失败；随后加入官方/旧兼容同色域曝光预设及研发 CLI 别名。独立 Python 读取器逐行核对 CUBE 的尺寸、恰好 `N³` 行、有限 RGB、R 最快节点顺序，并分别用 Sony V1.0 公式与旧 JS 冻结解析参数计算参考值。比较器对所有 33³/65³ 节点的三个通道统计最大、RMS、P99 尺度化误差和最差位置；门槛沿用标量阶段已冻结的 `2e-12`。

四份 CUBE 是从解析 Double 公式即时计算的研发输出，不是打包的内置 LUT，也不参与后续生成真值。官方原始技术 PDF、旧 JS 与参照夹具仍只存于 `research/`、`tests/`、`tools/`。
