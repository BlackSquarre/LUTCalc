# 2026-10-02 AWG3 与 SUP 3 显式 EI 非 UI 阶段验收

## 范围和来源

接续已冻结的 [Log C scene 接线](2026-10-02-logc-scene-routing.md)，新增色域身份 `arri.awg3.v1` 与 11 个 `arri.logc-sup3-ei{EI}-awg3-to-linear-ap0-published.v1` 预设。输入为 SUP 3 scene／AWG3，输出为 linear scene／AP0，Data→Data、曝光修正 0、CAT02；EI 必需且明确，不为缺参请求默认 EI 800。

AWG3 原色 R `(0.6840,0.3130)`、G `(0.2210,0.8480)`、B `(0.0861,-0.1020)`，D65 `(0.3127,0.3290)`，由 ARRI 2017 官方文档和 2012 公开镜像交叉核对。2017 官方 PDF SHA-256 为 `348d2761d3b1df259011204c7080ff9cfdc0512b3073f521384794f88fe1b665`。产品以 Double 从原色推导矩阵，不读取参照、PDF、旧引擎或采样表。

独立参照采用 Fraction Gauss–Jordan、精确 CAT02／Bradford 和 80／120 位 Decimal；两种精度转成 Double 一致。60 个双向矩阵案例覆盖当前 15 色域和两种 CAT。D-Gamut2 参数从用户提供的原始 CTL 解析，原字节 SHA 与既有独立夹具一致：`f4d38708eb7f1886e27dcc09f4d358f8ef8dbf986706fd0bb7fc2a90b76a90ff`。其原色推导 XYZ 再与既有独立 CTL 参照核对。2017 文档六位 XYZ 矩阵与原色推导结果最大差 `4.5143084397014643e-7`，记录舍入差异，不作为 `2e-12` 精度参照。

## 失败与实际验证

先行核心／项目契约 `contract-red.log` 因生产接口缺失退出 1。初轮生成器错误写入 D-Gamut2 原色，确定错误后保留脚本／未验收产物／日志，以 SIGTERM 终止；子进程退出 -15，外层退出 241。修正版本从 CTL 提取参数后重新生成，退出 0；没有因观察超时重启进程。

首次接线测试 `debug-first.log` 的预设／trace 通过，两项数值测试因参照 JSON 尚未生成完成失败，退出 1。参照生成完成后 `debug-final.log` 8 项／0失败。独立文件验证器初轮遗漏 Codable 省略默认 CAT02 的契约，退出 1；核对实际编码／解码规则后修正，重新验证通过，原失败保留。

完整 Release `release-final.log` **502 项／0失败／2项既有可选夹具跳过**。该轮包含加强后的 SPI1D 精确错误断言，以及既有六个本地 SIGKILL／独立重启回归；本包不把后者计为新增设备恢复证据。既有 UserLUTProjectAssetContractsTests 多余 `try` 警告保留。
