# H10 单调 1D 反求基础验收记录

日期：2026-09-23。环境：Apple Silicon，Command Line Tools Swift 6.2.1；完整 Xcode 与 iOS SDK 仍不可用。

## 修改与来源

新增 `LUTAnalysis/RootSolver.swift`、`MonotonicCurve1D.swift`、`LUTAnalysisChecks` 与 XCTest 用例。二分是保留的参考求解方法，Brent 使用括区间内的插值/二分回退。状态显式区分 `converged`、`notBracketed`、`nonUnique`、`nonFinite`、`maxIterations`、`cancelled` 和求值失败；成功不使用大数哨兵。用户 1D 曲线分析保留输入样本数组，不修改平段或端点来制造可逆性。默认容差使用数值契约中的 `xAbs=1e-12`、`xRel=4×ULP`、`fAbs=1e-12`、`fRel=2e-12`、128 次上限。

源码 SHA-256：`RootSolver.swift` 为 `2ad8c87d9026adff3c6b06ae4d3a409b78e003956e531b19c21244a43e8a2054`；`MonotonicCurve1D.swift` 为 `e00cdda0b60aab339ea483214a0d757c9467512d2fad1a0e984e3081b46f88da`；`LUTAnalysisChecks/main.swift` 为 `5adb4bdf4030f38ed6df250d4dea651b9338626317c293da2d9ba41d03c64766`。此包不引入厂商 LUT 或采样表。

## 实际命令与结果

`swift run --package-path Native/Packages/LUTKit LUTAnalysisChecks` 与 `swift run -c release --package-path Native/Packages/LUTKit LUTAnalysisChecks` 均通过。检查端点根、常值无根、目标为常值的非唯一平段、非有限求值、零次迭代、求值时取消注入、`x²=2` 的二分/Brent 对照，另有 7 个递增/递减线性或非线性目标交叉检查。用户 1D 样本 `[0, 0.5, 0.5, 1]` 对 `0.5` 返回平段非唯一，对 `0.75` 返回唯一根 `5/6`，原始样本保持不变。
