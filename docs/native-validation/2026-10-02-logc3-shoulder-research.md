# 2026-10-02 ARRI Log C 高 EI、旧路径差异与公开参数接缝研究

## 来源与适用范围

实际取得 [ARRI 官方 2017 文档](https://www.arri.com/resource/blob/31918/66f56e6abb6e5b6553929edf9aa7483b/2017-03-alexa-logc-curve-in-vfx-data.pdf)，文件 SHA-256 为 `348d2761d3b1df259011204c7080ff9cfdc0512b3073f521384794f88fe1b665`。来源为 Harald Brendel／Joseph Goldstone 的《ALEXA Log C Curve — Usage in VFX》，10 页，2017 修订。另取得同名 2012 文档的公开镜像（12 页，SHA `03970d2a35497e38d871f37c7128cc13b72d01b01c6a4e8b1ced65efd9daa680`），用于核对 SUP 2 及旧 SUP 3 参数；2017 文档已删除 SUP 2 附录。

PDF、PDFKit 实际提取的文本、下载 URL／重定向／时间和 SHA 保存在 `research/colour/2026-10-02-logc3/`。2012 文件是厂商文档的镜像，不将镜像托管位置写成现行 ARRI 官方入口。两份文档的 SUP 3 数值参数逐行相同。

2017 文档第 4、8、9 页仅给出 EI 160、200、250、320、400、500、640、800、1000、1280、1600 的紧凑公式参数，分别针对 sensor signal 和 exposure value。第 9 页明确说明 EI 大于 1600 无法用该紧凑公式表示；第 5 页指出 EI 1600 的高光也有相机 shoulder 差异，最高约 3%。本包不能用公开紧凑公式冒充全部实际相机的高 EI 曲线。

SUP 2 文档还说明其 RGB 为 raw camera RGB，不能直接借用 SUP 3 的 ALEXA Wide Gamut 语义。ISO 参数、线性域、色域、传感器裁剪和最后文件限幅须分别建模。

## 旧引擎最小复现

实际运行 `node tools/native-validation/probe-arri-logc-legacy-boundaries.js`，退出 0。该研发脚本仅调用原 `js/gamma.js` 中 `LUTGammaArri`，关闭范围包装，保留旧 0.9 线性单位换算，同时执行 `linToData`、`linToD` 和 `linFromData`。脚本和 JSON／日志在本次源码及 `artifacts/2026-10-02-logc-compact/` 留存，不进入 App 运行路径。

| 最小输入 | EI 1600 的实际旧结果 |
| --- | --- |
| 线性输入 1，标量编码 | `0.8986982884432779` |
| 线性输入 1，数组编码 | `0.5540897132715993` |
| 两路径绝对差 | `0.34460857517167864` |
| Data 输入 1，标量解码 | `79.68742368739633` |
| Data 输入 1.nextUp，标量解码 | `75.61285466812187` |
| 相邻输入的解码跳变 | `−4.074569019274463` |

标量编码的 knee 分支检查和映射的是原线性输入；数组编码映射的是编码后的值。解码超过 1 的延拓又以 1 为起点，而区间内 knee 在 1 处达到 `xm=1.0054194775781038`。EI 2000／2560／3200 的同类差异也已实际保存。EI 800 未启用 knee，标量／数组在所取编码点相等。

这些结果证明旧路径冲突，不能作为新数学实现正确性参照。需要明确旧兼容版本、公开公式版本及实际 shoulder 版本，禁止任选旧路径并称全量兼容。

## 公开十进制参数的接缝

紧凑公式为 `x > cut ? c*log10(a*x+b)+d : e*x+f`，解码为 `t > e*cut+f ? (10^((t-d)/c)-b)/a : (t-f)/e`。参数按文档十进制原值保存，分支边界明确采用 Double 的 `cut` 与 `e*cut+f`；选定分支的数学结果另用 80／120 位 Decimal 独立计算。

44 组公开参数（SUP 2／3 × sensor／scene × 11 EI）的最邻接探针显示：

- SUP 3、scene、EI 800 的编码接缝差为 `−2.501721051706429e-7`。
- 最大绝对接缝为 SUP 3、sensor、EI 500 的 `1.3566431744105323e-6`。

这是公开六位小数参数两段定义的差异，不是 Swift 实现误差。不能悄悄修改系数补连续性，也不能据这些公开解码式声称整段唯一、连续反求或逐位旧兼容。若建立连续模型，应另有算法身份和独立来源；现有 `2e-12` 门槛继续用于实现相对选定公开公式的误差。

## 研究阻塞及接续

**研究阻塞：** 实际高 EI shoulder 的可公开完整公式或独立高精度参照尚未取得；旧标量／数组和域外延拓互相冲突，EI 1600 的公开紧凑式还明确是相机高光近似。不能用厂商 LUT 填补，不将高 EI 映射到 800 或插值公开参数后冒充原模型。

继续推进已公开解析式、相机状态／稳定 ID／默认算法映射、ISO/EI 政策、显式项目参数与任务快照；缺少的曲线／空间及高 EI 分别阻塞。上述边界不阻止其他非 UI 工作。本包的公开内核验收另见后续阶段记录，FULL-02 与 Goal 保持未完成／active。
