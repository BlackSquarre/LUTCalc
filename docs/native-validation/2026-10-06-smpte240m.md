# SMPTE 240M 原生算法验收

日期：2026-10-06

## 范围

本次补齐研究清单 S06 的最小公开数学子集：SMPTE 240M 的分段 OETF／逆变换，以及独立的 SMPTE 240M D65 原色。它不解锁历史 Sony STD4 查表名称，也不携带厂商 LUT 或采样表。

实现使用 Swift `Double`。OETF 使用公开参数：线性阈值 `0.0228`、低段斜率 `4.0`、高段 `1.1115 * pow(L, 0.45) - 0.1115`；逆变换按对应编码阈值选择分支。原色为 `R(0.670,0.330)`、`G(0.210,0.710)`、`B(0.140,0.080)`、D65 `W(0.3127,0.3290)`，矩阵由运行时解析色度坐标推导。

来源：ITU-R BT.2380-0，SMPTE 240M 历史参数与色度报告，见 `SMPTE240MTransfer.referenceURL`。实现身份分别为 `smpte.240m.v1` 与 `smpte.240m-d65.v1`。
