# H11 Sony S-Log3 标量与最小计划阶段验收

日期：2026-09-24。状态：官方公式和旧兼容解析版本的标量、10/12-bit 全码及 8 个同色域曝光点通过；完整旧管线、33³/65³ 全网格及双端 App 尚未验收。

## 来源与冻结契约

Sony [S-Gamut3.Cine/S-Log3 Technical Summary V1.0](https://www.sony.jp/ls-camera/knowledge/pdf/TechnicalSummary_for_S-Gamut3Cine_S-Gamut3_S-Log3_V1_00.pdf) 的附录第 7 页给出 scene reflection 与 data 编码之间的双向分段公式，分段点为线性 `0.01125000`、编码 `171.2102946929/1023`；第 8 页给出 S-Gamut3.Cine 原色及 D65 白点，已与现有 `ColorPrimaries.sonySGamut3Cine` 的数值逐项核对。下载的原版 PDF 仅保存在 `research/`，SHA-256 为 `8ceeb250aebb8934bd8d4d6f04320a2cb37af2c23009661287c7ba7d359ec343`，不进入 App。官方材料的反向编码输入说明为 `0...1`；本实现对负值与域外值采用同一分段代数延伸，并明确不把这种延伸归为 Sony 官方定义域。

先用独立 Python `Decimal` 按原始公式在 80/120 位十进制精度下计算并核对一致，冻结分段相邻 Double、0/18%/90% 与扩展域标量、10/12-bit 共 5120 个完整码值及 8 个 RGB 曝光点。标量及计划的尺度化误差门槛在实现前定为 `2e-12`。随后从冻结的 `js/gamma.js` 注册项和 `LUTGammaLog` 方法抽取旧解析行为；旧线性单位的中灰是 `0.2`，参照比较时显式用 `scene = legacy × 0.9`，不能与 Sony scene reflection 混用。旧版系数是代码中的解析参数，并非采样表。

先添加 `LUTSLog3Checks` 契约；第一次编译按预期因缺少 `SLog3Transfer`、稳定 ID 和色域注册而失败。随后加入 Swift Double 分段函数、官方与旧兼容稳定 ID、S-Gamut3.Cine 注册及 `TransformPlan` 双向处理。标准版与旧版分开登记，不能以旧系数冒充官方精度。既有注册表数量契约同步从 5/3 更新为 7 曲线/4 色域，并继续验证全部稳定 ID、别名、来源及悬空引用。

## 实际命令与结果

- Apple Swift 6.2.1，arm64 macOS Command Line Tools；本机 Python 3.14.6、Node 18+。`python3 tools/native-validation/generate-slog3-reference.py --check` 退出码 0，80/120 位计算结果对所有冻结输入舍入到同一 Double；`node tools/native-validation/generate-slog3-legacy-baseline.js --check` 退出码 0。
- `swift run -c release --package-path Native/Packages/LUTKit LUTSLog3Checks tests/fixtures/native-contracts/slog3-sony-reference.json tests/fixtures/native-contracts/slog3-legacy-reference.json`：实现前编译失败；实现后退出码 0。官方标量及 10/12-bit 全码最大尺度化误差 `3.84969833788773e-14`；旧兼容对旧 JS 的最大尺度化误差 `2.846599929869882e-16`；8 个同色域曝光 RGB 点分别为 `5.137557046452912e-14` 和 `1.7763568394002505e-15`。
- 旧 JS 对官方独立参照在 10-bit 最大码值处的最大绝对差为 `1.9721975519360058e-7` scene reflection，最大尺度化差为 `5.133132720373097e-9`。这是已冻结样本内的差异，不扩展为任意设备/域上的精度宣称。
- 首次 `tools/native-validation/verify-native-subset.sh > /tmp/lutcalc-h11-slog3-scalar-20260924.log 2>&1` 因注册表数量契约仍写 5/3 而退出码 1；补齐新登记检查后，同一命令退出码 0。静态边界覆盖 51 个 Swift 源文件；旧 Node 9/9、Release 包与现有契约通过。未放宽原有阈值或修改已有夹具。
