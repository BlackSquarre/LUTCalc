# 2026-10-02 Blackmagic Film Gen5 非 UI 阶段验收

## 范围

本包新增公开 Blackmagic Film Gen5／Blackmagic Wide Gamut Gen5 算法，同时保留旧 LUTCalc BMDFilm Gen5 作为独立 legacy 身份。公开公式和原色来自固定 ACES 官方仓库提交 `29b722bccd529460696a8382394504cae2e88419` 的双向 CTL，来源文件 SHA-256 记录在 `research/colour/2026-10-02-bmdgen5/sources.json`。产品运行时不读取 CTL、JS 或任何 LUT 资源；公开曲线、旧曲线和原色均由 Swift `Double` 计算。

公开分段为 `x < 0.005` 时 `8.283605932402494*x + 0.09246575342465753`，否则 `0.08692876065491224*ln(x+0.005494072432257808)+0.5300133392291939`，逆函数使用相同边界。Gen5 原色为 R `(0.7177215,0.3171181)`、G `(0.2280410,0.8615690)`、B `(0.1005841,-0.0820452)`、白点 `(0.3127170,0.3290312)`。旧曲线保留 `js/gamma.js` 注册的九参数、自然底近似和 legacy grey 语义，不冒充公开 Gen5。

相机 resolver 现在可为四个使用 `BMDFilm Gen5`／`Blackmagic Wide Gamut` 的身份选择 legacy 或 published 默认：旧策略 22／66 可选，公开策略 31／66 可选。Pocket Film 等其他 Blackmagic 模型仍明确拒绝，不能用 Gen5 默认替换。
