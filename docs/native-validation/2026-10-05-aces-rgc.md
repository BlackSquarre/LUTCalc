# 2026-10-05 ACES 1.3 Reference Gamut Compression 数学子集验收

## 范围

本包实现 ACES 1.3 Reference Gamut Compression（RGC）静态算子及规范定义的闭式逆向 decompression。输入和输出均为线性 ACES 2065-1 RGB，内部按规范的 `TRA1` 转换到 ACEScg/AP1，使用 `A = MAX(R,G,B)`、归一化距离 `d_n`、逐通道 `l/t` 和 `p=1.2` 压缩或展开，再按 `TRA2` 转回 ACES 2065-1。实现位于 `LUTCore`，只使用 Swift `Double`；不读取或打包 LUT、`.labin`、采样数组，也没有接入 UI、项目 schema 或旧调节链。

规范来源为仓库保存的 `research/colour/2026-09-23/pages/aces-rgc.html`，对应 ACES Transform ID：

`urn:ampas:aces:transformId:v1.5:LMT.Academy.GamutCompress.a1.3.0`

产品内部算法身份为 `aces.reference-gamut-compression-1.3.0`。规范允许 `l` 之外的极端值仍留在 AP1 外，本实现不额外裁切或放宽定义域；非有限输入由 `RGB64`／算子拒绝。

## 独立参照结果

- Decimal 精度：90 位。
- 样本：5,069 个 RGB 点，包含 `3^3`、`5^3`、`17^3` 网格（范围 `[-0.5, 1.5]`）和负值、超白、非灰固定样例。
- 通道数：15,207。
- 最大尺度化误差：`4.4408920981579213e-16`。
- RMS 尺度化误差：`9.501859717569115e-17`。
- P99 尺度化误差：`2.220446049250313e-16`。
- 本包门槛：`2e-14`；未改变项目既有生成网格、位宽、插值规则或阈值。

逆向 Decimal 回放同样使用 5,069 个压缩输入和 15,207 个通道：

- 最大尺度化误差：`1.0058398558498993e-11`。
- RMS 尺度化误差：`1.2512460158004195e-13`。
- P99 尺度化误差：`5.10702591327572e-15`。
- 逆向门槛：`3e-9`。该门槛只覆盖规范 10 位矩阵在闭式逆奇异附近的条件放大，不改变正向门槛或算法公式。
