# H11 BT.1886 参考显示 EOTF 阶段验收

日期：2026-09-25。范围是 ITU-R BT.1886 Annex 1 的参数化 Double 标量 EOTF 与逆函数，以及原生注册表的归一化同空间计划。它不包含 HDR 峰值、OOTF、屏幕测量或 UI 接入。

## 公式与边界

依据归档资料 `research/colour/2026-09-23/text/whitepapers/itu-bt1886.txt`（来源登记见 `research/colour/2026-09-23/sources.json`）：

`L = a (V + b)^γ`，其中 `γ=2.4`，`a=(LW^(1/γ)-LB^(1/γ))^γ`，`b=LB^(1/γ)/(LW^(1/γ)-LB^(1/γ))`。`V=0…1` 映射到 `LB…LW`；逆函数按同一参数反解。实现保留 Double，并拒绝非有限值、负黑位、`LW≤LB`、非正指数和定义域外信号。
