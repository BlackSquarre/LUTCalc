# H09 共享参数页与导出流程草稿记录

日期：2026-09-23。用户明确要求 UI 先做草稿，详细设计将另行提供；当前布局、用语与交互均为临时实现，不作为最终设计验收。

## 修改与版本

在 `LUTSharedUI` 新增 `EditorSession.swift`，用 `@MainActor @Observable` 保存每窗口会话、参数修订号和导出状态。数值草稿只有解析为有限 Double 并提交后才改变有效曝光。`makeSnapshot()` 冻结当前计划，导出在后台 `GenerationCoordinator` 中运行，成功记录请求时的参数与版本。`ContentView.swift` 改为 SwiftUI 表单草稿，提供已验证子集的输入范围、曝光、输出目标、17/33/65 尺寸、生成、取消和系统分享入口；macOS/iOS App 入口仍引用同一共享视图。新增 `LUTSessionChecks` 与 XCTest 合同用例。

源码 SHA-256：`EditorSession.swift` 为 `233a810bae827f7e3c7486986d531b7addf5b199f2c245d1cf39ec69766982c8`；`ContentView.swift` 为 `d739e85d6a6f977d9218e415b53388855d3d5e478db2e5fac36c50572f7379ae`；`LUTSessionChecks/main.swift` 为 `4dd3e582b87dd4d55151409e44fcd2ff7ffdce69dbac3654e189d5a3ad6c99e5`。数值来源、夹具哈希与首条链误差见 H01–H07 记录。

## 实际命令与结果

`swift run --package-path Native/Packages/LUTKit LUTSessionChecks` 与 `swift run -c release --package-path Native/Packages/LUTKit LUTSessionChecks` 均通过，且 SwiftUI 共享包已编译。检查了：不完整的 `-` 草稿不会提交；随后将曝光从 +1 改为 +2 时，旧请求仍保留 +1 的不可变参数；会话用 +2 的新请求生成 17³ CUBE，读回 4913 个节点且导出记录保存 +2 与请求修订号。测试生成的自有临时文件已在检查结束后清理。
