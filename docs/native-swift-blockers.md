# LUTCalc 剩余阻塞清单

更新：2026-10-02。按用户要求，所有 UI 实现与交互验收暂缓。当前完整非 UI 待办及优先级见[范围核对](native-validation/2026-10-02-non-ui-scope-audit.md)；这里只列阻塞，不把未实现功能都称为外部阻塞。

## 研究阻塞

1. 任意 3D LUT 反求与 transfer/colour 分离没有唯一可证明解；当前实现只接受明确的单调 1D 或已知可逆仿射模型。
2. 多个旧厂商风格条目只有采样 LUT，没有公开连续公式，不能把拟合模型冒充等价算法。
3. 完整 ACES 输出变换、HDR/OOTF/设备显示参数和部分 ICC LUT 类型需要独立规范与参照。
4. `.ncp` 写出、部分旧格式方言和目标软件兼容缺少足够的机型/软件实测资料。
5. 旧 tricubic 红轴域外外插的蓝导数索引与独立仿射参照冲突；域内 tricubic 已通过，域外不能猜测修复后宣布旧兼容。最小复现见[旧 tricubic 验收](native-validation/2026-10-01-legacy-tricubic.md)。
6. 旧白平衡 Kelvin／Duv／Dpl 依赖来源未闭合的 501 点 Planck 轨迹；不得直接复制该表或用未验证近似替代。已保存实际参数与矩阵最小复现，见[轨迹研究](native-validation/2026-10-02-white-balance-locus-research.md)。CAT 基础矩阵可用不等于完整旧白平衡完成。
7. 旧 PSST-CDL 的 `psstF/B/Y/M` 固定环缺对应连续生成定义；默认控制对彩色输入也存在非恒等差异，不能用标准 HSV 或跳过算子冒充等价。实际依赖和最小复现见[固定环研究](native-validation/2026-10-02-psst-fixed-rings-research.md)。

## 外部平台阻塞

1. iPhone 11 八种格式本地保存、回调字节回读和独立 Files 列表发现已有证据；真实 iCloud/File Provider 授权撤销、替换竞争、磁盘故障及进程终止恢复仍未验收。
2. 独立设备集 iPad 模拟器已成功创建／启动并取得文稿 URL 打开证据；Xcode destination 仍不发现它，当前 Xcode 缺少 Simulator 图形 App。该环境和所有 UI 验收按用户要求暂缓。
3. 第三方软件往返、发行渠道、签名／公证与安装升级证据尚缺。完整发布清单必须在所有 H01–H14、平台、精度和文档证据真实完成后生成；当前保持缺失。

## 处理原则

阻塞项不会通过猜公式、隐藏失败、降低网格或放宽误差阈值解决。每项继续保留来源、最小复现、实际命令和受影响能力，其他规范明确的工作继续推进。
