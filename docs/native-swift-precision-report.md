# LUTCalc 原生精度说明

## 计算约束

- 生成、矩阵、曲线、插值和文件写出路径使用 Swift `Double`。
- 3D 节点采用冻结的 R-fast 坐标顺序；不通过降低网格、位宽、插值方法或放宽阈值来通过验证。
- 公式验证同时保留独立 Decimal/Python 参照和 Swift 结果；旧 JavaScript 只作为兼容基线，不作为错误行为的正确性来源。

## 已有数值证据

- D-Log2/D-Gamut2 33³ 往返最大绝对误差约 `1.42e-13`。
- H11 批量公式和 CUBE 读回覆盖 33³/65³；当前 CUBE 独立读回门槛为尺度化误差 `2e-12`。
- 已验证的 sRGB、Rec.709、S-Log3、LogC4、V-Log、Apple Log、HLG、BT.1886、F-Log2、I-Log、Mi-Log、L-Log、KineLOG3、ACEScc、ACEScct 和 ACESproxy 子集均保留各自阶段报告中的独立误差。
- Swift Release 测试、原生数值子集、54 对 33³/65³ CUBE 生成与读回均已通过最近一次回归。
- ASC-CDL 的旧内核／独立全网格／跨色域 Decimal 子集最大尺度化误差分别为 `1.7763568394002505e-15`、`1.3322676295501878e-15`、`1.2754909529580394e-15`，见[阶段记录](native-validation/2026-10-02-asc-cdl.md)。
- SDR Saturation 的 33³／65³ 独立全网格最大尺度化误差 `7.216449660063518e-15`，RMS `3.2451425962689393e-16`，P99 `1.2212453270876722e-15`；实际旧解码／色域／曝光／CDL／SDR 17³ 组合最大尺度化误差 `2.777793995638905e-13`。统计定义和未覆盖范围见[阶段记录](native-validation/2026-10-02-sdr-saturation.md)。
- Multitone 的 33³／65³ 独立 70 位 Decimal 全网格最大尺度化误差 `1.201189098608258e-12`，RMS `1.8378469776699792e-15`，P99 `3.3000957105406944e-15`；实际旧解码／色域／曝光／CDL／Multitone／SDR 17³ 子链最大尺度化误差 `5.667610467233136e-13`。首轮 Double 参照在近零 Y 节点失败，独立高精度复算定位到参照自身舍入误差；原失败日志保留，产品计算／域／网格／`2e-12` 门槛未改。见[阶段记录](native-validation/2026-10-02-multitone.md)。

## 限制

上述结果只证明相应公式、设置和样本集合。它们不证明完整旧调节链、HDR/EDR 屏幕显示、所有 ICC 类型、任意 3D 反求或所有历史格式已等价迁移。没有独立参照的项目继续标记为研究阻塞。
