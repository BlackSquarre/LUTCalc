# 历史实现

本目录保存已经迁移出主目录的历史实现，供兼容、回归验证和迁移审计使用。

## Web

`legacy/web/` 是原有的浏览器版 LUTCalc。HTML、CSS、JavaScript、浏览器依赖、图像资源以及旧版 `.labin` 资源均集中在此处。仓库根目录的同名符号链接保留旧入口和脚本路径，便于现有部署与验证继续运行。

## 其他语言实现

当前仓库中的 Python 代码按用途放在 `tools/`、`tests/` 和 `research/` 下：验证工具、测试代码和研究资料分别管理；原生产品代码集中在 `Native/`。新增 Python 工具应放入对应的用途目录，不要放回仓库根目录或 `legacy/web/`。
